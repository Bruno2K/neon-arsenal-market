# Agent Task Template

Use this structure for every autonomous engineering task.

## Objective
One sentence describing the required outcome.

## Invariant
State the business or technical invariant that must remain true.

## Scope
List what may change.

## Out of scope
List adjacent work that must not be included.

## Acceptance criteria
Use observable, testable statements.

## Required context
Name only the files/docs that are necessary to begin. Follow `context-policy.md` for expansion.

## Roles
- Primary:
- Review:
- Verification:

## Implementation constraints
Include architecture, compatibility, security, data and operational constraints.

## Verification
List the narrowest useful checks first, followed by broader checks when required.

## Handoff
Use `docs/agents/handoff-template.md`.

## Completion rule
The task is complete only when acceptance criteria are satisfied, verification evidence exists, and relevant documentation has been updated.
