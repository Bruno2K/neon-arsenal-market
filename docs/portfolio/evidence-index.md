## Evidence boundaries

The repository does **not** prove production capacity, sustained SLO attainment, multi-region availability, provider account controls, production OTLP reception, or a recoverable live managed backup. Public endpoints establish only point-in-time reachability. See [project status and frozen backlog](project-status.md).
